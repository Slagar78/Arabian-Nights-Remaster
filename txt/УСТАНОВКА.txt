========================================================================
             ИНСТРУКЦИЯ ПО УСТАНОВКЕ И СБОРКЕ ПРОЕКТА
                      "ARABIAN NIGHTS REMAKE"
========================================================================

Для того чтобы запустить игру и собрать проект на новом компьютере, 
необходимо выполнить следующие шаги.

--------------------------------------------------------------------
ШАГ 1. УСТАНОВКА ОКРУЖЕНИЯ (MSYS2)
--------------------------------------------------------------------
1. Скачайте и установите MSYS2 с официального сайта: https://www.msys2.org/
2. Установите по стандартному пути (обычно C:\msys64).
3. После установки ОБЯЗАТЕЛЬНО запустите консоль, на ярлыке которой 
   написано "MSYS2 UCRT64". (Не используйте MSYS, MINGW64 или другие 
   консоли! Цвет ярлыка не важен, главное - название).

--------------------------------------------------------------------
ШАГ 2. УСТАНОВКА КОМПИЛЯТОРА И БИБЛИОТЕК
--------------------------------------------------------------------
В открывшейся консоли (MSYS2 UCRT64) введите следующую команду 
(можно скопировать целиком) и нажмите Enter:

pacman -S mingw-w64-ucrt-x86_64-gcc-fortran mingw-w64-ucrt-x86_64-make mingw-w64-ucrt-x86_64-SDL2 mingw-w64-ucrt-x86_64-SDL2_image mingw-w64-ucrt-x86_64-SDL2_ttf

(Когда консоль спросит подтверждение [Y/n], нажмите Y и Enter. 
Дождитесь окончания загрузки и установки всех пакетов).

--------------------------------------------------------------------
ШАГ 3. СТРУКТУРА ПРОЕКТА
--------------------------------------------------------------------
Скопируйте папку с проектом в удобное место. 
Например: C:\msys64\home\<ВАШЕ_ИМЯ>\projects\Arabian_Nights

Убедитесь, что в папке проекта есть следующие файлы и папки:
- Makefile
- src/ (исходный код .f90)
- data/ (файлы карт .txt)
- assets/ (кнопки, тумблеры, шрифты)
- assets_game/ (тайлсеты, спрайты персонажей, портреты)

--------------------------------------------------------------------
ШАГ 4. СБОРКА И ЗАПУСК
--------------------------------------------------------------------
1. Откройте консоль MSYS2 UCRT64 (ту самую, с правильным названием).
2. Перейдите в папку с проектом командой:
   cd ~/projects/Arabian_Nights
   (или cd /c/msys64/home/<ВАШЕ_ИМЯ>/projects/Arabian_Nights)

3. Для компиляции проекта введите:
   make

4. Для запуска игры (с автоматическим копированием нужных DLL) введите:
   make run

--------------------------------------------------------------------
ВАЖНЫЕ ПРИМЕЧАНИЯ
--------------------------------------------------------------------
1. НЕ ЗАПУСКАЙТЕ app.exe двойным кликом из проводника Windows! 
   Рядом с ним должны лежать SDL2.dll, SDL2_image.dll и SDL2_ttf.dll. 
   Команда "make run" автоматически копирует их из системной папки MSYS2.

2. Для отображения текста в меню используется системный шрифт Windows 
   (C:/Windows/Fonts/arial.ttf). Если его нет, игра не вылетит, но текст 
   может не отобразиться.

3. Если вы изменили код в папке src/ и хотите пересобрать проект заново:
   make clean
   make run
